Current State

Why Fargate Is Failing Us

No SSH Access
Debugging means parsing CloudWatch logs with zero ability to run commands or inspect live state.
15-20 Minute Deploys
Every deploy requires a container build, ECR push, new task definition, and ECS drain cycle.
Queue Workers Don't Work
ECS kills containers mid-deploy. In-flight jobs are dropped. Everything runs synchronously, causing 100% CPU spikes.
Paying for Dead Weight
The pompa-wss ECS task is a duplicate of our existing EC2 WSS server. It runs 24/7 behind its own ALB doing nothing.

Scale

Horizontal Scaling When We Need It

No architecture changes required. Each new instance is identical to the first and connects to the same shared data layer.

Add Web Capacity
Spin up another t3.small, point it at Aurora and Valkey, drop it behind a Caddy proxy or ALB. No code changes.
~5 min setup
Add Worker Capacity
Spin up another t3.micro, point it at Valkey queue, Supervisor starts pulling jobs. Completely independent and stateless.
~5 min setup
New API Services
Same pattern. Small EC2, GitHub Actions deploy, shared data layer. Each service isolated, cheap to run, easy to reason about.
same playbook
